# 0008. Ship a hardened container with a hashed lock file and an optional Basic guard

- Status: Accepted
- Date: 2026-10-04

## Context

The app ran only from a local venv, with floating dependency ranges and no
access control. Running it on a server needs a reproducible image, a way to
keep the UI from being open to anyone who reaches the port, and a CI path for
the container. Jobs are held in memory (`app/main.py`), and the extractor and
rebuilder use PyMuPDF's built-in fallback fonts (`app/fonts.py`), not system
fonts.

## Decision

- **Lock file.** `requirements.lock` is generated by `make lock` with `uv`
  (a dev-only tool, not in `requirements.txt`) for Linux and Python 3.12, with
  hashes. The image installs it with `pip install --require-hashes`. It does
  not cover Windows or macOS; local venvs keep using `requirements.txt`.
- **Base image.** `python:3.12-slim` pinned by digest, plus `fonts-noto-cjk`.
  Measured: 526 MB on disk / 163 MB content with the fonts, 356 MB / 86.5 MB
  without. The current code does not read system fonts, so the fonts are unused
  today; they are kept for future use at the operator's request.
- **Access guard.** `app/access.py` applies HTTP Basic when `APP_PASSWORD` is
  set: any user name, the password must match, `/healthz` stays open. Unset
  means off (local use) and a startup warning is logged. TLS is expected from a
  reverse proxy. Use a long random password and rate-limit at the proxy; the
  app has no lockout.
- **Runtime.** One uvicorn worker, because job state is in memory. Compose
  binds `127.0.0.1` only, with `read_only`, `cap_drop` and
  `no-new-privileges`.
- **CI.** `eval-real.yml` is a manual workflow using the `ANTHROPIC_API_KEY`
  secret. Until a `make eval-real` target exists it runs `make eval` with
  `APP_PROVIDER=anthropic`.

## Alternatives considered

- Plain `requirements.txt` in the image: no hash verification, builds drift.
- Image without fonts: 170 MB smaller, but fonts would have to be added later.
- Basic guard replaced by a user database or OAuth: more code and state than
  the single-operator use case needs.
- Several uvicorn workers: jobs would not be visible across processes.

## Consequences

- Dependency changes now require `make lock`; the lock must be committed.
- The image is larger by about 170 MB for fonts nobody reads yet.
- Basic credentials travel in clear without a TLS proxy; the compose binding
  to localhost limits exposure until one is in place.
- Scaling out needs external job storage first.
