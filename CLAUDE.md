# CLAUDE.md

PDF Translator: translates PDF documents (Chinese, Japanese, Korean, English,
French) into French or English with an LLM while preserving the page layout.
Extraction, layout and reconstruction are deterministic (PyMuPDF); only the
translation step calls a model. FastAPI single-page web UI + CLI.

## Architecture

| Path | Role |
| --- | --- |
| `app/main.py` | FastAPI app: upload, job status, zip download, purge of job files |
| `app/pipeline.py` | One job end to end: validate -> extract -> dedup/cache -> translate -> rebuild |
| `app/extractor.py` | Text blocks with bbox, font, color; scanned-page detection |
| `app/translator.py` | `Translator` interface, `MockTranslator`, `GatewayTranslator` (alias of `LLMTranslator`), `get_translator` |
| `app/llm/` | `LLMProvider` protocol; Anthropic, Gateway and Fake providers; `LLMTranslator`; `PromptBuilder`; retry; factory; `CachedProvider` and `TracingProvider` wrappers |
| `prompts/` | Versioned prompt files (`prompts/<llm.prompt_version>/`) |
| `app/config.py` | Loads `config.yaml`, validates the `llm`, `rag`, `verification`, `tracing`, `cache` sections |
| `app/rebuilder.py` | Redact original blocks, reinsert translations (shrink, then truncate) |
| `app/scanned.py` | Optional multimodal path for scanned pages |
| `app/fonts.py` | Font per script, glyph-loss detection |
| `app/cache.py` | Per-block translation cache keyed by hash(model, prompt version, src, tgt, text) |
| `app/auth.py` | OAuth2 device-code flow for the gateway provider |
| `app/verification/` | Deterministic checks on LLM answers (JSON, count, glossary, numbers, dates), retry-then-flag policy, `review.json` data |
| `prompts/` | Versioned prompt files (`prompts/v1/`), e.g. `retry_corrections.md` |
| `evaluation/` | Evaluation suites, `baseline.json` (protected), reports in `evaluation/reports/` |
| `tests/` | Plain-script tests (`check()` + `main()`), fixtures generated by `tests/make_fixtures.py` |
| `.claude/` | Agentic workflow: agents, skills, hooks, handoff schema (see below) |

Configuration: `config.yaml` (no secrets). Secrets: `.env` (never read it,
never commit it); variable names are in `.env.example`.

## Commands

Use the venv interpreter: `.venv/Scripts/python.exe` (Windows) or
`.venv/bin/python`. `make` finds it automatically, also from a worktree.

| Command | What it does |
| --- | --- |
| `make test` | All test modules, hook tests included (`scripts/run_tests.py`) |
| `make lint` / `make format` | ruff check + format check / apply |
| `make eval` | Evaluation suites vs `evaluation/baseline.json`; exit 1 on regression |
| `make validate` | Consistency of `.claude/` (agents, skills, hooks, schema, settings) |
| `make security` | Secret + forbidden-term scan of tracked files |
| `make audit` | pip-audit of `requirements.txt` (network) |
| `make check` | lint + test + validate + security: run before every push |
| `uvicorn app.main:app` | Run the web UI on http://127.0.0.1:8000 |
| `python -m app.pipeline FILE --src zh --tgt en --provider mock` | Translate from the CLI |

## Conventions

- Python 3.11+, type hints, English for code, comments, docs and commits.
- Tests never call a real LLM or network: use `MockTranslator` /
  `httpx.MockTransport`. Each behaviour change ships with a test.
- New dependency: pin it and justify it (commit body or `docs/decisions/`).
- Logs carry ids and counters only: never document text, file names, tokens.
- A failed batch becomes a job warning; a job never dies on one bad block.
- Commits: `<type>(<scope>): <summary>`, type in feat/fix/test/docs/refactor/chore.

## Definition of done

`make check` passes; `make eval` reports no regression; new behaviour is
tested; docs match the code; no secret, `.env` content or employer/client
reference anywhere in the diff.

## Critical rules

- Never read or write `.env*` (except `.env.example`).
- Never edit `evaluation/dataset/` or `evaluation/baseline*.json`: they are
  the yardstick. Only a human runs `make eval-baseline`.
- No `rm -rf`, no force push, no `git reset --hard` on main. Never push
  without the human.
- Test data is synthetic or public with its source cited. No real contracts.

These rules are enforced by hooks in `.claude/hooks/`; a blocked action
means change the approach, not work around the hook.

## Agents and when to delegate

Entry points: `/feature <description>` (full workflow), `/eval`,
`/release-check` (before any push). Details: `docs/agentic-development.md`.

| Agent | Delegate when | Model |
| --- | --- | --- |
| `planner` | A request spans several files or steps: split it into independent tasks with acceptance criteria | opus |
| `implementer` | One planned task must be coded + tested (runs in its own git worktree) | sonnet |
| `reviewer` | A diff needs a verdict against its acceptance criteria (approve / changes_requested) | opus |
| `evaluator` | Metrics must be compared with the baseline (after a change, before a release) | haiku |
| `security-auditor` | A change touches secrets, logging, uploads, dependencies, Docker or CI | opus |
| `docs-writer` | README, decision notes or diagrams must follow a change | sonnet |

Every agent ends by writing `.claude/handoffs/<task_id>.<agent>.json`
(schema: `.claude/schemas/handoff.schema.json`); the SubagentStop hook
refuses to let it stop until the file is valid.
